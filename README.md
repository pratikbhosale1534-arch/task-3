# Task 3 — Advanced Styling and JavaScript

## Features
- Responsive design using CSS media queries.
- Interactive multiple-choice quiz with answer feedback and score.
- JavaScript carousel with previous/next and dot controls.
- Fetches a random programming joke from the public JokeAPI, with error handling and fallback text.

## Run
Extract the ZIP and open `index.html` in Chrome or Edge. Internet is needed only for the live joke API. No installation or database is required.

## Test
Resize the browser, complete the quiz, use carousel controls, fetch a joke, and test the fallback with internet disabled.
